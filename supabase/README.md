# supabase/

Carpeta para migraciones SQL (`supabase/migrations`) y, si corresponde, Edge Functions (`supabase/functions`). Se puebla a partir de **Fase 2** (modelo de datos) y **Fase 3** (RLS).

Requiere Supabase CLI (`npx supabase init` / `supabase link`) cuando se cree el proyecto real en Supabase — pendiente de que confirmes la organización/proyecto a usar.
